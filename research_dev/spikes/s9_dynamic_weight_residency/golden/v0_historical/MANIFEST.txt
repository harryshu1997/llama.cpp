Status of the V0 result (RELABELED after the review)
  SUITES PASS; MECHANICS NOT YET CERTIFIED; CAPACITY UNPROVEN.

  The V0 suites (53 schema fixtures + 23 semantic + 28 sim checks) all pass, but the
  review found that several of the mechanics those suites claimed to prove were
  fail-OPEN, so a green V0 suite did NOT certify the mechanics:
    - one physical byte-charge conflated the canonical allocation with each backend
      prepared image (no refcounted alias ownership);
    - PreparedImage identity did not bind preparation algorithm / derived payload sha;
    - dispatch eligibility was checked as scalar booleans, not as an exact required
      == satisfied tuple set;
    - the simulator divided ONE shared USB controller by the phone count instead of
      selecting real per-device candidates, and had no D2H return leg;
    - not every request reached an explicit terminal outcome (horizon / rejected);
    - byte reservations were taken at publish time only, without per-stage acquire +
      rollback, so a transient oversubscription could not be observed;
    - the causal score summed microseconds, bytes, and permille into one dimensionless
      integer (not a valid cost or documented lexicographic objective).

  These are the exact items repaired in the V0-R round. This artifact stays frozen as
  the "before" side of the red-before / green-after evidence.
